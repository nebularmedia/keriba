# Keriba demo temporal

Sube el contenido de esta carpeta a la raíz del repositorio **keriba**.
Incluye el archivo oculto `.nojekyll`. No subas la carpeta contenedora ni el ZIP.
Activa Settings > Pages > Deploy from a branch > main > /(root).
La URL será https://TU-USUARIO.github.io/keriba/.

Las rutas están preparadas para /keriba/. Si cambia el nombre del repositorio,
regenera el paquete con preparar-github-pages.py --repo NOMBRE.

La demo es pública. Las páginas llevan noindex. Esto no es protección de acceso.
El formulario es demostrativo y no envía datos. Las operaciones de tienda enlazan
a la web actual. No se incluyen credenciales, informes internos ni presentaciones.
Los canónicos y referencias editoriales identifican la web original de Keriba.
Desactiva GitHub Pages al terminar la presentación.
